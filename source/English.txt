# returns the embedded T("...") keys directly. This file lives in source/ only as
# the single source of truth for generating the lang/*.txt translations.
# Format: EnglishSource=Translation
# Lines starting with # or ; are comments. Missing lines fall back to English.
# The Game Guide and Plugin Guide text are NOT translated here.
#
# CHARACTER BUDGETS (translations longer than this get clipped with '..'):
#   HOME categories (Movement/Tools/...): ~12 chars   [tight!]
#   Cheat names: ~26 chars                            (big font)
#   Folder / tool / picker names: ~28 chars
#   Settings labels: ~16 chars (a value sits on the right)
#   Search form field labels: 15 chars              (small font)
#   Search field values / enum names: ~26 chars     (small font)
#   Hints / footers: ~40 chars                      (small font)
#   Rule: prefer a shorter synonym over overflowing. Accents OK in the
#   big-font items; the small-font search form strips accents (e->e).
